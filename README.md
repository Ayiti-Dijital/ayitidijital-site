# Ayiti Dijital

**Sit Ayiti Dijital la** – diksyonè Kreyòl, jwèt, gramè, flashcard ak lòt zouti louvri pou lang Kreyòl la.
Ayiti Dijital se yon asosyasyon san bi likratif ki bati enfrastrikti dijital louvri pou Ayiti.

**Estati:** byento – pifò seksyon yo poko gen kontni.

## English

The website of Ayiti Dijital, a nonprofit building open digital infrastructure for Haiti: a portal to the
Kreyòl dictionary, games and other tools for the Kreyòl language. Kreyòl only for now.

```bash
pnpm install
pnpm start        # dev server on http://localhost:4200
pnpm test         # unit tests (Vitest)
pnpm build        # static, prerendered site in dist/ayitidijital-site/browser
```

Angular 22, Tailwind CSS v4, pnpm. Every page is prerendered to static HTML: no server, no backend, nothing
loaded from other servers.
